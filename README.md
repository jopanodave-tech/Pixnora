# Pixnora - Create. Animate. Inspire.

**Pixnora** est une plateforme web moderne alimentée par l'IA qui transforme vos idées en contenus visuels puissants.

## 🌟 Fonctionnalités

- **Création IA rapide** : Générez des contenus visuels en secondes
- **Design moderne** : Interface époustouflante avec dégradés et animations
- **Responsive** : Fonctionne parfaitement sur tous les appareils
- **Performance** : Chargement rapide et optimisé
- **Accessibilité** : Navigation facile et intuitive

## 📋 Sections du site

1. **Navbar** - Navigation sticky avec menu mobile responsive
2. **Hero** - Section d'accueil avec appel à l'action
3. **Fonctionnalités** - Grille de 6 cartes détaillant les avantages
4. **Tarification** - 3 plans avec présentation premium
5. **Avis** - Témoignages de 3 utilisateurs satisfaits
6. **CTA** - Appel à l'action final
7. **Footer** - Navigation secondaire et liens sociaux

## 🛠 Technologies utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Styling moderne avec variables CSS
- **JavaScript** - Interactivité et animations
- **Font Awesome** - Icônes
- **Responsive Design** - Mobile-first approach

## 📱 Responsive Breakpoints

- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px
- Small Mobile: < 480px

## 🎨 Palette de couleurs

- **Primaire** : #6e00ff (Violet)
- **Secondaire** : #00f0ff (Cyan)
- **Dark** : #0a0a14 (Noir profond)
- **Light** : #f8f9fa (Gris très clair)

## ⚡ Optimisations

- Animations au scroll avec Intersection Observer
- Menu mobile avec hamburger responsive
- Effets ripple sur les boutons
- Navigation sticky avec shadow au scroll
- Dégradés et transparences pour effet moderne

## 🚀 Utilisation

1. Clonez le repository
2. Ouvrez `index.html` dans votre navigateur
3. Ou déployez sur GitHub Pages, Vercel, ou Netlify

## 📝 Fichiers

- `index.html` - Structure HTML complète
- `styles.css` - Feuille de styles avec animations
- `script.js` - Interactions et animations JavaScript
- `README.md` - Documentation
